# Tekla Audit Plugin

This project is the starting point for a Tekla Structures 2024 plugin that:

- audits selected objects in Tekla
- falls back to all model objects when nothing is selected
- checks workmanship and rebar rules
- exports the result as a .xlsx workbook

Save all four files here: C:\Program Files\Tekla Structures\2024.0\bin\plugins\Tekla\Model\TeklaAuditPlugin
restart tekla 2024 to view the plugin.

link to demo : https://lnkd.in/p/dG33rzjr
